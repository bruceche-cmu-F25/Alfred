# Sky × Pi Web · Study 02

独立、可丢弃的交互样稿。**不是工作台上加一个 AI 入口，而是由 Robin 把内容带到你面前。**

## 打开

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory /Users/bruce/Alfred/prototype/pi-web-sky
```

- 新版：http://127.0.0.1:4173/
- 上一版保留对照：http://127.0.0.1:4173/v1/

静态服务器只监听本机。与 Pi Web 的 30141 端口和真实服务独立。

## 怎么体验

推荐先点右上角 **「看一段演示」**，约 20 秒：

1. 先只有 Robin 和一个安静的空间，不显示日程／笔记，也不打开聊天弹窗。
2. 演示提问「今天有什么安排？」后，Sky 从中央让开，日程沿它的方向展开。
3. 台词提到两点的讨论、三点的留白、四点半的散步时，相应内容被强调；窄屏只滚动纸面，不移动输入框。
4. 演示追问「项目讨论的笔记呢？」后，日程退下，笔记接上；Sky 指向正在介绍的段落。
5. 「我先读一下」让 Sky 缩小、退到一旁，停止讲解，内容留在面前。

也可以直接点击快捷提问、日程里的项目讨论，或输入包含「日程／安排」「笔记」「先读」「收起」的文字。右侧声纹按钮只模拟一句语音提问。

- **静音演示**：台词、形象、内容共用一套时间线，但没有音频。
- 暂停／继续、下一句、停止均可操作；点击 Sky 可暂停／继续当前讲解。
- 新提问打断旧时间线；收起后旧台词不会把内容重新打开。
- 关闭纸面／点左上角 Robin：收起内容，回到身边。
- Esc：正在讲解时先停止；否则收起内容。
- 浅色／夜色、减少动态效果都只作用于本页。
- 系统减少动态效果时，shader 静止、空间位移瞬间完成、台词默认暂停，可逐句推进。页面隐藏会暂停讲解，回来不会擅自继续。
- 未发送草稿保留到刷新为止，没有跨设备／重启续接。

## 明确没有做

没有修改、导入或调用 `pi-web-robin` 的运行代码。无真实用户资料、任务、笔记、日程、密钥或模型；无 API、WebSocket、麦克风、语音合成、外部字体、数据库或浏览器持久存储。

CSP 阻止连接、媒体和表单网络提交。所有时间和内容都是固定演示；关键词分支不是模型能力，文案「找到」不代表访问过真实资料。

## 实现边界

- `index.html`：一个舞台、同一个 Sky、两个内容面和一个输入框；无导航应用壳、无聊天弹窗。
- `styles.css`：独立视觉 token。形象／纸面使用 transform、opacity 过渡；500ms 仅用于这段解释型场景交接，普通控件不等待动画。纸面退出即 inert，焦点回到输入框。
- `app.js`：固定台词的单一时间线驱动形象状态、内容、指示位置；新请求清除旧计时器。几何只在场景／尺寸改变时测量，不逐帧布局。
- `sky.js`：沿用 Alfred `prototype/forms.html` 的 Sky / Clouds shader 及 MIT 来源标注；单个 512px WebGL 源，空闲约 20fps、介绍约 30fps，隐藏暂停，减少动态效果静止；WebGL 不可用时保留 CSS 静态形象和全部交互。
- `v1/`：之前「首页＋聊天弹窗」样稿的独立快照。
- `previews/v2/`：新版场景截图；外层 `previews/` 是上一版截图。

## 检查

保持静态服务器运行后：

```bash
node /Users/bruce/Alfred/prototype/pi-web-sky/check.mjs
```

默认使用 Pi Web 已安装的 Playwright；可以用 `PLAYWRIGHT_MODULE` 指定其他现有安装，不安装依赖。

覆盖：真实计时的台词／纸面指示联动、整段演示、暂停／逐句／停止、新请求抢占、阅读／收起、焦点与草稿、文本安全、页面隐藏暂停、两种配色、320／375／390／768／1440px、812×375 横屏、390×500 短视口、减少动态效果、WebGL 降级；拦截 API／录音／音频／持久存储以确认零真实操作。

验收范围是桌面 Chromium 和模拟尺寸，不是手机真机 GPU 性能、软件键盘或 Safari 验收。
