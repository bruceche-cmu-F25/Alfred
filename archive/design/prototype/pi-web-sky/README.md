# Sky × Pi Web · Study 03

独立、可丢弃的交互样稿。Robin 是主体，但**注意力转向内容时，它就把空间让出来**。

## 打开

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory /Users/bruce/Alfred/prototype/pi-web-sky
```

- 当前版：http://127.0.0.1:4173/?hour=night
- 上一版（主体舞台）：http://127.0.0.1:4173/v2/
- 最初版（首页＋聊天弹窗）：http://127.0.0.1:4173/v1/

服务器只监听本机，与 Pi Web 30141 端口、真实服务独立。

## 这次改变了什么

### 空间跟着注意力走

- **闲聊**：Sky、台词、输入紧挨成一个居中的整体，不再把输入钉到远处的屏幕底部。
- **介绍内容**：Sky 退到左边缘的小范围内；桌面日程／笔记使用约八成宽度和可用高度，输入随内容区居中。
- **宽屏内容**：日程左侧是时间线，右侧是当前事项的相关内容，随台词同步；笔记正文与讨论问题并排，不把每行文字无限拉长。
- **阅读**：Sky 再缩到左上侧，停止介绍，不再占住左半屏。结束阅读后可以直接继续问。
- **窄屏**：Sky 与台词收成顶部一行，纸面使用余下空间；保留内部滚动和可触达输入框。
- 切换两份内容时不先回到中央绕一圈；收起内容才回到身边。

### 原型的四种时段色彩

顶部可选 **清晨 dawn／白天 day／黄昏 dusk／深夜 night**。`?hour=` 可直达，不用持久存储。

`styles.css` 的四条热色带、amber 和 Sky ink **逐值沿用** `/Users/bruce/Alfred/prototype/forms.html`；`sky.js` 沿用其指数渐变系数 `1 - exp(-4 * dt)`，没有自行重配球体颜色。用户给的蓝白球对应 **night**，也是默认选项。

深浅纸面由太阳按钮独立切换，**不会把 Sky 的颜色切走**。减少动态效果时颜色直接切到目标，WebGL 降级形象也使用同一套色值。

### 连续、可反向的移动

`stage-spring.mjs` 只负责当前舞台的七个数值（形象位置／半径、台词位置、输入位置）：独立临界阻尼弹簧，damping ratio 1、response 0.4s。新目标保留当前显示位置和速度，不从上一个逻辑目标重新开始；不锁输入、不加入拖拽或第三方动画依赖。

纸面沿同一路径进出。坐标只在场景／尺寸变化时测量，弹簧帧只写 transform。不使用形象与内容之间的连线；通过让位动作、台词和内容高亮表达关联。

## 怎么体验

先点右上角 **「看一段演示」**，约 20 秒：

> 问今天 → Sky 让到左边 → 日程展开并随台词指向安排 → 追问项目笔记 → 笔记接上 → 「我先读一下」→ Sky 缩到旁边。

也可点快捷提问、日程里的讨论／相关笔记，或输入包含「日程／安排」「笔记」「先读」「收起」的文字。

- 台词是**静音演示**，不播放声音。
- 声纹按钮只模拟一句提问，没有录音权限请求。
- 暂停／继续、下一句、停止都可用；点击 Sky 可暂停或继续讲解。
- 新提问打断旧时间线；关闭纸面不会被迟到的旧台词重新打开。
- Esc：讲解时先停止，否则收起内容。切换时段不会丢失场景和草稿。
- 减少动态效果：形象静止、位置直接到目标、台词默认暂停，可以逐句推进。
- 标签页隐藏会暂停；返回后不会自行继续。
- 未发送草稿只存在于当前文档，刷新即清空。

## 隔离边界

没有修改、导入或调用 `pi-web-robin` 的运行代码。无真实用户资料、任务、笔记、日程、密钥或模型；无 API、WebSocket、麦克风、语音合成、外部字体、数据库或浏览器持久存储。

CSP 禁止连接、媒体和表单网络提交。全部文案／时间／资料都是固定示例；关键词分支不是模型理解，「找到」不表示访问过真实资料。浅色阅读材料是本 mock 的补充，不是原型本身的浅色版本。

## 文件与检查

- `index.html`：一个舞台、两个内容面、同一个输入区及四时段按钮。
- `styles.css`：原型配色、响应式内容排版、独立的浅色材料。
- `app.js`：固定台词时间线、内容／注意力分配、时段与草稿。
- `stage-spring.mjs`：当前显示位置及速度的连续变化。
- `sky.js`：来自 `forms.html` 的 Clouds shader，保留 MIT 来源标注；512px 离屏 WebGL 源、空闲约 20fps／介绍约 30fps、隐藏暂停和 CSS 降级。
- `v1/`、`v2/`：之前两版的独立快照。
- `previews/v3/`：本版桌面、手机及四时段截图；旧截图未覆盖。

运行静态服务器后：

```bash
node /Users/bruce/Alfred/prototype/pi-web-sky/check.mjs
```

使用 Pi Web 已安装的 Playwright；可用 `PLAYWRIGHT_MODULE` 指向其他现有安装，不安装依赖。

检查包含：与 `forms.html` 对比六个配色色值、四组 shader 像素确实不同、阅读材料不改变球体、切换色彩保留场景和草稿、左边缘与内容占比、输入／内容不遮挡、弹簧中途反向、真实计时联动、暂停／逐句／停止／抢占、焦点／文本安全、320–1920px／横屏／短视口、减少动态效果及 WebGL 降级。拦截网络／录音／音频／存储以确认零真实操作。

验收是桌面 Chromium 和模拟尺寸；不是手机真机 GPU、软件键盘或 Safari 验收。
